# HighPen for Windows

- **한국어:** 지금 보고 있는 문서입니다.
- **English:** [Read this document in English.](README.en.md)
- **日本語:** [日本語版のドキュメントはこちらです。](README.ja.md)

[← HighPen 소개로 돌아가기](../README.md)

비대면 강의용 Windows 펜 앱입니다. 화면 위에 바로 필기하고, 마우스 포인터를 스팟으로 강조하고, 화면을 확대하고, 칠판과 쉬는 시간 타이머를 띄울 수 있습니다. 와콤 같은 펜 태블릿(Windows Ink)과 마우스를 모두 지원합니다.

![HighPen 설정바와 마우스 스팟](../screen/전체화면1.png)

## 설치

### Microsoft Store에서 설치 (권장)

[<img src="https://get.microsoft.com/images/ko%20dark.svg" width="200" alt="Microsoft Store에서 받기"/>](https://apps.microsoft.com/detail/9PDG1QN5QSL3?mode=direct)

SmartScreen 경고 없이 설치되고, 새 버전이 나오면 자동으로 업데이트됩니다. 제거는 Windows 설정의 **설치된 앱**에서 합니다.

### winget으로 설치

터미널(PowerShell 또는 명령 프롬프트)에서 실행합니다. Microsoft Store 패키지를 설치하므로 Store에서 설치한 것과 같습니다.

```
winget install 9PDG1QN5QSL3 --source msstore
```

- 처음 설치할 때 Microsoft Store 약관 동의를 묻습니다. `Y`를 누르거나, 묻지 않게 하려면 `--accept-package-agreements --accept-source-agreements`를 붙입니다.
- 이름으로 찾기: `winget search HighPen --source msstore`
- 업데이트: Store가 자동으로 업데이트합니다. 직접 하려면 `winget upgrade 9PDG1QN5QSL3`
- 제거: `winget uninstall 9PDG1QN5QSL3`

### 설치 없이 실행

[HighPen.exe](https://github.com/stepanowon/high-pen/releases/download/v1.8.0/HighPen.exe)를 다운로드해서 바로 실행합니다. 설치 과정이 필요 없습니다.

### 설치 파일로 설치

1. [HighPen-Setup.exe](https://github.com/stepanowon/high-pen/releases/download/v1.8.0/HighPen-Setup.exe)를 다운로드해서 실행합니다.
2. 설치 여부와 바탕화면 바로가기 생성 여부를 선택합니다.
3. 설치가 끝나면 바로 실행할 수 있습니다.

- 설치 위치: `%LOCALAPPDATA%\Programs\HighPen` (관리자 권한 불필요)
- 시작 메뉴에 바로가기가 만들어집니다.
- 같은 파일을 다시 실행하면 덮어써서 업데이트됩니다.
- 제거: Windows 설정의 **설치된 앱**에서 HighPen을 제거하거나 설치 폴더의 `Uninstall.exe`를 실행합니다. 저장된 설정(`%APPDATA%\HighPen`)은 남습니다.
- 조용한 설치/제거: `HighPen-Setup.exe /S`, `Uninstall.exe /S`
- 설치 안내 문구는 Windows 표시 언어를 따릅니다(한국어, 일본어, 그 외에는 영어).

### 받은 파일 확인

실행 파일은 [GitHub 릴리스](https://github.com/stepanowon/high-pen/releases)에서만 배포합니다. 코드 서명이 없으므로, 받은 파일이 릴리스에 올린 파일과 같은지 [SHA256SUMS.txt](https://github.com/stepanowon/high-pen/releases/download/v1.8.0/SHA256SUMS.txt)의 값과 비교해 확인할 수 있습니다.

```powershell
Get-FileHash .\HighPen-Setup.exe -Algorithm SHA256
```

### 작업표시줄에 고정

앱을 실행하면 작업표시줄에 HighPen 아이콘이 나타납니다. 우클릭 → **작업 표시줄에 고정**을 선택하면 다음부터 앱이 꺼져 있어도 아이콘으로 실행할 수 있습니다.

### 요구 사항

Windows 10/11 (.NET Framework 4.8 포함, 별도 설치 불필요)

## 사용 방법

실행하면 작업 모니터의 좌측 상단에 설정바가 나타납니다. 설정바 맨 위 줄(HighPen)을 끌어 옮길 수 있고 위치는 기억됩니다. `<` 버튼으로 접고 펼 수 있습니다.

### 언어 바꾸기

기본 언어는 **English**입니다. 처음 실행하면 버튼과 툴팁이 영어로 표시되며, 실행 중에 다음 방법으로 바꿀 수 있습니다.

1. 설정바의 **Settings** 버튼을 누르거나 `Ctrl+Alt+D`를 눌러 설정 패널을 엽니다.
2. 패널 아래쪽 **Language** 항목에서 **한국어**(또는 日本語)를 누릅니다.
3. 앱을 다시 시작하지 않아도 바로 바뀌며, 사용 중이던 펜·확대 등의 상태도 그대로 유지됩니다.

고른 언어는 자동 저장되어 다음 실행 때도 그대로 쓰입니다.

단축키는 전역 단축키라서 다른 프로그램을 쓰는 중에도 동작합니다. 다른 프로그램이 이미 쓰는 조합은 등록되지 않으며, 이때는 실행 직후 화면 아래에 등록하지 못한 단축키를 알려 주고 설정 패널에도 표시합니다. 버튼에 마우스를 올리면 이름과 단축키가 툴팁으로 표시됩니다. 아래 표는 기본 단축키이며, 설정 패널의 **단축키 설정**에서 바꿀 수 있습니다.

| 버튼 | 단축키 | 기능 |
|---|---|---|
| 스팟 | Ctrl+Alt+S | 마우스 포인터를 따라다니는 원형 스팟 켜기/끄기. 아래 화면의 클릭은 그대로 통과합니다. |
| 펜 | Ctrl+Alt+P | 화면 위에 필기. 펜을 끄면 필기는 화면에 남고 마우스는 아래 화면으로 통과합니다. 지우개/말풍선 상태에서는 펜으로 전환합니다. |
| 형광펜 | Ctrl+Alt+L | 반투명한 굵은 펜으로 글자나 그림 위를 칠합니다. 아래 내용이 비쳐 보이고, 펜 필기보다 아래에 그려집니다. 한 번 더 누르면 끕니다. |
| 지우개 | Ctrl+Alt+E | 획 단위로 지웁니다. 지우개 상태에서 한 번 더 누르면 현재 페이지의 펜 필기와 말풍선을 모두 삭제합니다. |
| 칠판 | Ctrl+Alt+B | 흰 칠판 → 검은 칠판 → 끄기 순서로 전환. 화면 위 필기와 두 칠판의 필기는 각각 따로 보관됩니다. |
| 되돌리기 | Ctrl+Alt+Z | 마지막 필기나 지우개 작업을 취소합니다. |
| 지우기 | Ctrl+Alt+C | 현재 페이지의 필기와 말풍선을 모두 지웁니다. |
| 말풍선 | Ctrl+Alt+T | 클릭한 위치에 텍스트 메모를 붙입니다. Enter 확정, Shift+Enter 줄바꿈, Esc 취소. |
| 확대 | Ctrl+Alt+X | 마우스 포인터가 있는 모니터를 확대합니다. 배율은 설정에서 1.5배, 2배, 2.5배 중 선택합니다. |
| 확대 고정 | Ctrl+Shift+X | 확대 중에 확대 화면을 그 자리에 고정하거나 고정을 풉니다. 고정하면 마우스를 움직여도 확대 화면이 움직이지 않고, 확대 버튼에 "확대 고정"이 표시됩니다. |
| 캡처 | Ctrl+Alt+F | 작동 모니터의 화면을 필기·칠판·말풍선과 함께 PNG로 저장하고 클립보드에 복사합니다. 설정바와 스팟은 찍히지 않습니다. |
| 쉬는 시간 | Ctrl+Alt+W | 쉬는 시간 타이머를 시작하고 끝냅니다. 작동 모니터 전체에 남은 시간이 크게 표시됩니다. |
| 설정 | Ctrl+Alt+D | 설정 패널을 열고 닫습니다. |
| 정보 | | 저작자(이름, 이메일, GitHub 저장소)와 라이선스 정보를 보여 줍니다. 링크를 누르면 메일 앱이나 브라우저가 열립니다. |
| `<` | Ctrl+Alt+H | 설정바를 접고 폅니다. |
| 빨간 X | Ctrl+Alt+Q | 종료 |

### 단축키 바꾸기

설정 패널 아래쪽의 **단축키 설정**을 누르면 모든 기능의 단축키 목록이 열립니다.

1. 바꿀 기능의 단축키 칸을 누릅니다. 칸에 "키를 누르세요…"가 표시됩니다.
2. 새 조합을 누릅니다. Ctrl 또는 Alt를 함께 눌러야 하며, F1~F24는 단독으로도 쓸 수 있습니다.
3. 바로 저장되고, 창을 닫으면 새 단축키가 적용됩니다.

- **Esc**는 입력 취소, **Delete**(또는 Backspace)는 그 기능의 단축키를 없앱니다.
- HighPen의 다른 기능이 이미 쓰는 조합이면 어느 기능이 쓰는지 알려 주고 받지 않습니다.
- 다른 프로그램이 전역 단축키로 쓰는 조합은 그 프로그램이 먼저 가져가므로 눌러도 반응이 없습니다. 다른 조합을 고르세요.
- **기본값으로**를 누르면 모든 단축키가 처음 상태로 돌아갑니다.
- 창이 열려 있는 동안에는 HighPen 단축키가 잠시 꺼집니다.

### 확대 중 필기

확대 중에 펜을 켜면 확대 화면이 그 자리에 고정되어 보이는 위치에 그대로 필기할 수 있습니다. 펜을 끄면 확대 화면이 다시 포인터를 따라갑니다. 필기는 원래 화면 좌표로 저장되므로 확대를 끄면 같은 내용 위에 원래 크기로 남습니다.

## 기능 설명

### 마우스 스팟

마우스 포인터를 따라다니는 반투명 원형 스팟으로, 시청자가 포인터 위치를 쉽게 찾도록 도와줍니다.

- 스팟은 클릭을 가로채지 않아서 아래 화면을 평소처럼 조작할 수 있습니다.
- 색상(8가지)과 크기(20~200)는 설정 패널에서 바꿉니다. 테두리 없이 색만 있는 원입니다.
- 작동 모니터로 선택한 모니터에서만 표시됩니다.

### 펜 (필기)

화면 위에 투명한 필기 층을 덮어서 그대로 그립니다. 와콤 펜과 마우스 모두 사용할 수 있습니다.

![화면 위 필기](../screen/펜1.png)

- **펜 켜기:** 펜을 켜면 화면이 필기 모드가 되어 아래 화면의 클릭이 막힙니다.
- **펜 끄기:** 그려 둔 필기는 화면에 남고, 마우스는 다시 아래 화면을 조작합니다. 필기 위에서 발표 자료를 넘길 수 있습니다.
- **색상과 두께:** 색 8가지, 두께 1~30. 색상은 단축키로도 바꿉니다.
- **필압 반영:** 켜 두면 펜을 세게 누를수록 선이 굵어지고, 설정한 두께는 중간 필압 기준입니다. 마우스는 설정한 두께로 일정합니다. 필압이 안 먹으면 와콤 드라이버에서 Windows Ink 사용이 켜져 있는지 확인합니다.
- **자동 보정:** 선은 부드러운 곡선으로 보정됩니다.

### 형광펜

교재의 문장이나 그림을 강조할 때 씁니다. 형광펜 버튼(Ctrl+Alt+L)을 누르고 그리면 반투명한 굵은 선이 그려집니다.

- 겹쳐 칠해도 진해지지 않고 아래 내용이 비쳐 보입니다. 펜 필기 위를 칠해도 펜 글씨는 형광펜 위에 그대로 보입니다.
- 색(기본 노랑)과 두께(기본 20)는 설정 패널의 **형광펜 색상**, **형광펜 두께**에서 바꿉니다. 형광펜을 쓰는 중에는 펜 색상 단축키(Ctrl+Shift+R 등)가 형광펜 색을 바꿉니다.
- 지우개, 되돌리기, 지우기는 펜 필기와 똑같이 적용됩니다.
- 펜 버튼을 누르면 일반 펜으로 돌아갑니다.

### 지우개

펜으로 그린 획 위를 지나가면 그 획 전체가 지워집니다(획 단위 지우기). 와콤 펜 뒤쪽 지우개 끝도 사용할 수 있습니다.

- 지우개 상태에서 Ctrl+Alt+E를 한 번 더 누르면 현재 페이지의 펜 필기와 말풍선이 한꺼번에 지워집니다. 다른 페이지에는 영향이 없습니다.
- 다시 쓰려면 펜 버튼(Ctrl+Alt+P)을 누릅니다.

### 칠판

화면 전체를 흰색 또는 검은색 칠판으로 덮고 그 위에 씁니다. 칠판 버튼을 누를 때마다 흰 칠판 → 검은 칠판 → 끄기로 바뀝니다.

- 화면 위 필기, 흰 칠판, 검은 칠판의 필기는 각각 따로 보관됩니다. 칠판을 껐다 켜도 내용이 유지되고, 칠판 필기가 화면 위 필기에 섞이지 않습니다.
- 검은 칠판에서 펜이 검정이거나 흰 칠판에서 펜이 흰색이면 안 보이므로 자동으로 반대 색으로 바꿉니다.
- 칠판에서는 확대 배율이 필기에 적용되지 않습니다.

### 되돌리기 / 지우기

- **되돌리기:** 현재 페이지에서 마지막 작업을 취소합니다. 펜으로 그린 획 하나, 또는 지우개로 한 번 문질러 지운 획들이 한 단계입니다. 전체 지우기도 한 단계로 되돌릴 수 있고, 이때 지운 말풍선도 함께 돌아옵니다. 말풍선을 하나씩 되돌리지는 못합니다.
- **지우기:** 현재 페이지의 필기와 말풍선을 모두 지웁니다. 다른 페이지(화면 위, 흰 칠판, 검은 칠판)에는 영향이 없습니다.

### 말풍선

화면에 텍스트 메모를 붙이는 기능입니다. 손글씨 대신 용어나 설명을 또렷한 글자로 남길 때 씁니다.

1. 말풍선 버튼(Ctrl+Alt+T)을 누릅니다. 포인터가 글자 입력 모양으로 바뀝니다.
2. 글을 놓을 위치를 클릭하고 내용을 입력합니다.
3. **Enter**로 확정합니다. **Shift+Enter**는 줄바꿈, **Esc**는 취소입니다.

- 흰 바탕에 현재 펜 색 테두리가 있는 둥근 상자로 표시되고, 글자 크기는 펜 두께에 비례합니다.
- 한 번 입력하면 일반 펜 모드로 돌아옵니다. 여러 개를 달려면 그때마다 버튼을 다시 누릅니다.
- 만든 뒤에는 위치를 옮기거나 고칠 수 없고, 지우기로만 삭제됩니다.
- 현재 페이지(화면 위, 흰 칠판, 검은 칠판)에 붙고 페이지별로 따로 보관됩니다.

![필기와 말풍선](../screen/펜2.png)

### 화면 확대

마우스 포인터가 있는 모니터를 실시간으로 확대합니다. 배율(1.5배·2배·2.5배)은 설정 패널에서 고를 수 있으며, 확대 중에 바꾸면 바로 적용됩니다.

![화면 확대](../screen/화면%20확대.png)

- 포인터 아래의 내용이 확대 후에도 포인터 바로 아래에 있도록 화면이 따라 움직입니다. 보이는 위치를 그대로 클릭하면 됩니다.
- 설정바는 확대되지 않고 원래 크기로 유지됩니다.
- 확대를 켠 순간 포인터가 있던 모니터가 확대되고, 확대 중에는 포인터가 그 모니터 밖으로 나가지 않습니다. 다른 모니터를 확대하려면 확대를 껐다가 포인터를 옮긴 뒤 다시 켭니다.
- 확대 중에 작동 모니터를 바꾸면 확대가 자동으로 꺼집니다.
- **확대 화면 고정 (Ctrl+Shift+X):** 확대 중에 누르면 확대 화면이 그 자리에 고정되어, 마우스를 움직여도 화면이 이리저리 움직이지 않습니다. 확대 버튼의 이름이 "확대 고정"으로 바뀝니다. 한 번 더 누르면 다시 포인터를 따라갑니다. 확대를 끄면 고정도 풀립니다.
- 고정 중에는 보이는 화면과 실제 클릭 위치가 다릅니다. 고정된 화면에서는 설명하거나 펜으로 필기하고, 클릭하려면 고정을 푸세요.
- **확대 중 필기:** 펜을 켜면 확대 화면이 그 자리에 고정되어 보이는 위치에 그대로 필기할 수 있습니다. 펜을 끄면 확대 화면이 다시 포인터를 따라갑니다. 필기는 원래 화면 좌표로 저장되므로 확대를 끄면 같은 내용 위에 원래 크기로 남습니다. 확대된 화면에서 다른 곳으로 옮기려면 펜을 끄고 포인터를 옮긴 뒤 다시 켭니다.

### 캡처

칠판이나 화면 위 필기를 강의 자료로 남길 때 씁니다. 캡처 버튼(Ctrl+Alt+F)을 누르면 작동 모니터에 보이는 그대로(화면, 필기, 칠판, 말풍선, 확대 화면) 찍습니다.

- **저장 위치:** `사진\HighPen\HighPen_날짜_시각.png`. 같은 이미지가 클립보드에도 복사되어 바로 붙여 넣을 수 있습니다.
- 설정바와 마우스 스팟은 찍히지 않습니다.
- 캡처 후 화면 아래에 저장 경로가 잠깐 표시되고, 누르면 탐색기에서 파일이 있는 폴더가 열립니다.

### 쉬는 시간 타이머

강의 중 쉬는 시간에 남은 시간을 보여 줍니다. 쉬는 시간 버튼(Ctrl+Alt+W)을 누르면 작동 모니터 전체가 어두워지고 남은 시간이 크게 표시되어, 화면 공유로 보는 수강생도 쉽게 알 수 있습니다.

- **시간 설정:** 설정 패널의 **쉬는 시간**에서 10분·15분·1시간·1시간 30분 버튼이나 슬라이더(5~120분, 5분 단위)로 고릅니다. 고른 시간은 저장되어 다음 실행 때도 쓰입니다. 타이머가 도는 중에 바꾸면 다음 쉬는 시간부터 적용됩니다.
- 남은 시간 아래에 다시 시작하는 시각(예: "13:26에 다시 시작합니다")이 표시되고, 마지막 1분은 주황색으로 바뀝니다.
- 시간이 다 되면 빨간 00:00과 "쉬는 시간이 끝났습니다"가 표시된 채 남아 있습니다. 쉬는 시간 버튼이나 Ctrl+Alt+W를 다시 누르면 닫힙니다.
- 타이머 화면은 클릭을 통과시키므로 쉬는 시간 중에도 PC를 그대로 쓸 수 있고, 설정바는 타이머 화면 위에 그대로 보입니다.

### 클릭 표시

녹화나 화면 공유에서 시청자가 어디를 눌렀는지 알 수 있도록, 클릭한 자리에 원이 퍼졌다가 사라집니다. 설정 패널의 **클릭 표시** 또는 Ctrl+Alt+K로 켜고 끕니다.

- 왼쪽 클릭은 실선, 오른쪽 클릭은 점선 원으로 표시되고, 색은 스팟 색상을 따릅니다.
- 작동 모니터에서만 표시되며, 펜으로 필기하는 동안에는 표시하지 않습니다.

### 다중 모니터

설정 패널의 **작동 모니터**(또는 Ctrl+Alt+M)로 앱이 동작할 모니터를 고릅니다. 필기, 스팟, 칠판, 설정바가 그 모니터에서만 나타나고, 다른 모니터는 평소처럼 쓸 수 있습니다. 모니터를 바꿔도 기존 필기와 말풍선은 유지됩니다. 번호는 Windows 디스플레이 설정의 번호와 같습니다. 실행 중에 모니터를 연결하거나 빼면 모니터 목록과 창 위치를 자동으로 다시 맞춥니다(확대 중이었다면 확대는 꺼집니다). 작동 모니터의 연결이 끊어지면 1초 안에 메인 모니터로 옮겨 가고, 그 모니터를 다시 연결하면 원래 모니터로 돌아옵니다. 모니터 순서가 바뀌어도 고른 모니터를 기억합니다.

### 설정바

- 맨 위 줄(HighPen)을 끌어서 옮기면 위치가 저장되어 다음 실행 때 같은 자리에 나타납니다. 저장된 위치가 화면 밖이면 좌측 상단으로 돌아옵니다.
- 설정바는 작동 모니터 밖으로 나가지 않습니다. 끌어서 옮길 때도, 펼치거나 설정 패널을 열어 커질 때도 작동 모니터의 작업 영역(작업표시줄 제외) 안에 머뭅니다.
- 맨 위 줄 왼쪽의 `<` 버튼으로 접고 펼 수 있습니다. 접으면 HighPen 제목도 사라지고 `>` 버튼만 남아서, 설정바 뒤에 가려져 있던 화면을 클릭할 수 있습니다. `>`를 누르면 같은 자리에 다시 펼쳐집니다. 접힌 상태에서는 설정바를 끌어 옮길 수 없습니다.

- 설정 패널은 설정바 오른쪽에 열리고, 설정바가 화면 오른쪽 끝에 있어 공간이 부족하면 왼쪽에 열립니다.
- 각 버튼에 마우스를 올리면 이름과 단축키가 툴팁으로 표시됩니다.
- 클릭해도 발표 중인 화면의 포커스를 가져가지 않습니다.
- 실행 중에는 작업표시줄에 아이콘이 나타나고, 고정해 둘 수 있습니다.

### 자동 업데이트

GitHub에서 받은 `HighPen.exe`나 `HighPen-Setup.exe`로 쓰는 경우, HighPen을 시작할 때마다 새 버전이 나왔는지 확인합니다. Microsoft Store 버전은 Store가 자동으로 업데이트하므로 확인하지 않습니다.

- 새 버전이 있으면 작동 모니터 가운데에 업데이트 창이 뜹니다. **업데이트**를 누르면 새 버전을 내려받아 설치하고 HighPen을 다시 시작합니다. **나중에**를 누르면 다음에 시작할 때 다시 알려 줍니다. **변경 내용 보기**를 누르면 릴리스 페이지가 열립니다.
- 다시 시작하면 화면의 필기는 지워집니다. 설정은 그대로 남습니다.
- 설치 파일로 설치했다면 새 설치 파일을 조용히 실행해 업데이트하고, 설치 없이 `HighPen.exe`만 쓴다면 그 파일을 새 버전으로 바꿉니다.
- 내려받은 파일은 릴리스의 `SHA256SUMS.txt` 값과 비교해서, 다르면 설치하지 않습니다.
- `HighPen.exe`를 쓰기 권한이 없는 폴더에 두었다면 업데이트하지 못합니다. 이때는 **변경 내용 보기**에서 직접 받으세요.
- 확인을 끄려면 설정 패널의 **업데이트 확인**을 누릅니다. 인터넷에 연결되어 있지 않으면 아무것도 표시하지 않습니다.

### 설정 저장

펜 색상, 두께, 필압 반영, 형광펜 색상과 두께, 바꾼 단축키, 스팟 색상과 크기, 스팟 켜짐 여부, 클릭 표시, 확대 배율, 쉬는 시간 길이, 작동 모니터, 설정바 위치, 언어, 업데이트 확인 여부가 `%APPDATA%\HighPen\settings.txt`에 자동 저장되어 다음 실행 때 그대로 쓰입니다.

## 참고 / 제한 사항

- 실행 파일에 코드 서명이 없어서 웹에서 직접 받으면 Windows SmartScreen 경고가 뜰 수 있습니다. Microsoft Store나 winget으로 설치하거나, 경고 창에서 **추가 정보 → 실행**을 누르세요.
- 모니터마다 화면 배율이 다른 환경에서는 확대나 설정바 위치가 어긋날 수 있습니다.
- USB-C↔HDMI 같은 변환 어댑터를 거쳐 연결한 모니터는 모니터 쪽 케이블을 뽑아도 Windows가 연결이 끊어진 것으로 보지 않을 수 있습니다. 이때는 HighPen도 옮겨 가지 않으니, 어댑터를 PC에서 뽑거나 디스플레이 설정에서 **이 디스플레이 연결 끊기**를 사용하세요.
- 확대 중에 펜을 쓰려면 확대 화면이 포인터를 따라 움직이지 않도록 펜을 켜 둔 상태여야 합니다.
