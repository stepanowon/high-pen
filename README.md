# HighPen

비대면 강의용 Windows 펜 앱입니다. 화면 위에 바로 필기하고, 마우스 포인터를 스팟으로 강조하고, 화면을 확대하고, 칠판을 띄울 수 있습니다. 와콤 같은 펜 태블릿(Windows Ink)과 마우스를 모두 지원합니다.

## 설치

### 설치 파일로 설치

1. `dist\HighPen-Setup.exe`를 실행합니다.
2. 설치 여부와 바탕화면 바로가기 생성 여부를 선택합니다.
3. 설치가 끝나면 바로 실행할 수 있습니다.

- 설치 위치: `%LOCALAPPDATA%\Programs\HighPen` (관리자 권한 불필요)
- 시작 메뉴에 바로가기가 만들어집니다.
- 같은 파일을 다시 실행하면 덮어써서 업데이트됩니다.
- 제거: Windows 설정의 **설치된 앱**에서 HighPen을 제거하거나 설치 폴더의 `Uninstall.exe`를 실행합니다. 저장된 설정(`%APPDATA%\HighPen`)은 남습니다.
- 조용한 설치/제거: `HighPen-Setup.exe /S`, `Uninstall.exe /S`

### 작업표시줄에 고정

앱을 실행하면 작업표시줄에 HighPen 아이콘이 나타납니다. 우클릭 → **작업 표시줄에 고정**을 선택하면 다음부터 앱이 꺼져 있어도 아이콘으로 실행할 수 있습니다.

### 설치 없이 실행

`dist\HighPen.exe`를 바로 실행해도 됩니다.

### 요구 사항

Windows 10/11 (.NET Framework 4.8 포함, 별도 설치 불필요)

## 사용 방법

실행하면 작업 모니터의 좌측 상단에 설정바가 나타납니다. 설정바 맨 위 줄(HighPen)을 끌어 옮길 수 있고 위치는 기억됩니다. `<` 버튼으로 접고 펼 수 있습니다.

| 버튼 | 기능 |
|---|---|
| 스팟 | 마우스 포인터를 따라다니는 원형 스팟 켜기/끄기. 아래 화면의 클릭은 그대로 통과합니다. |
| 펜 | 화면 위에 필기. 펜을 끄면 필기는 화면에 남고 마우스는 아래 화면으로 통과합니다. |
| 지우개 | 획 단위로 지웁니다. |
| 칠판 | 흰 칠판 → 검은 칠판 → 끄기 순서로 전환. 화면 위 필기와 두 칠판의 필기는 각각 따로 보관됩니다. |
| 되돌리기 | 마지막 획 하나를 취소합니다. |
| 지우기 | 현재 페이지의 필기와 말풍선을 모두 지웁니다. |
| 말풍선 | 클릭한 위치에 텍스트 메모를 붙입니다. Enter 확정, Shift+Enter 줄바꿈, Esc 취소. |
| 확대 | 마우스 포인터가 있는 모니터를 2배로 확대합니다. |
| 설정 | 설정 패널을 엽니다. |
| 빨간 X | 종료 |

### 설정 패널

- **작동 모니터**: 앱이 동작할 모니터를 선택합니다. 필기, 스팟, 칠판, 설정바가 선택한 모니터에서만 나타납니다.
- **펜 색상 / 두께**: 색 8가지(빨강, 주황, 노랑, 초록, 파랑, 보라, 검정, 흰색)와 두께 1~30.
- **필압 반영**: 펜을 세게 누를수록 선이 굵어집니다. 마우스는 설정한 두께로 일정하게 그려집니다.
- **스팟 색상 / 크기**: 색 8가지와 크기 20~200.

설정은 자동 저장되며 `%APPDATA%\HighPen\settings.txt`에 있습니다.

### 확대 중 필기

확대 중에 펜을 켜면 확대 화면이 그 자리에 고정되어 보이는 위치에 그대로 필기할 수 있습니다. 펜을 끄면 확대 화면이 다시 포인터를 따라갑니다. 필기는 원래 화면 좌표로 저장되므로 확대를 끄면 같은 내용 위에 원래 크기로 남습니다.

## 단축키

전역 단축키라서 다른 프로그램을 쓰는 중에도 동작합니다. 다른 프로그램이 이미 쓰는 조합은 등록되지 않을 수 있습니다.

### 기능 (Ctrl + Alt + 키)

| 단축키 | 기능 |
|---|---|
| Ctrl+Alt+P | 펜 켜기/끄기 (지우개/말풍선 상태에서는 펜으로 전환) |
| Ctrl+Alt+E | 지우개. 지우개 상태에서 한 번 더 누르면 현재 페이지의 펜 필기를 모두 삭제 |
| Ctrl+Alt+B | 칠판 전환 (흰색 → 검정 → 끄기) |
| Ctrl+Alt+Z | 되돌리기 |
| Ctrl+Alt+C | 전체 지우기 (필기 + 말풍선) |
| Ctrl+Alt+T | 말풍선 |
| Ctrl+Alt+S | 마우스 스팟 켜기/끄기 |
| Ctrl+Alt+X | 2배 확대 켜기/끄기 |
| Ctrl+Alt+M | 작동 모니터 순환 |
| Ctrl+Alt+R | 필압 반영 켜기/끄기 |
| Ctrl+Alt+D | 설정 패널 열기/닫기 |
| Ctrl+Alt+H | 설정바 접기/펴기 |
| Ctrl+Alt+Q | 종료 |

### 펜 색상 (Ctrl + Shift + 색상명 첫 글자)

| 단축키 | 색상 |
|---|---|
| Ctrl+Shift+R | 빨강 (Red) |
| Ctrl+Shift+O | 주황 (Orange) |
| Ctrl+Shift+Y | 노랑 (Yellow) |
| Ctrl+Shift+G | 초록 (Green) |
| Ctrl+Shift+B | 파랑 (Blue) |
| Ctrl+Shift+P | 보라 (Purple) |
| Ctrl+Shift+K | 검정 (blacK, B는 파랑이 사용) |
| Ctrl+Shift+W | 흰색 (White) |

설정바의 버튼이나 설정 패널의 색 위에 마우스를 올리면 해당 단축키가 툴팁으로 표시됩니다.

## 빌드

.NET SDK 없이 Windows에 기본 설치된 .NET Framework 컴파일러를 사용합니다.

```powershell
.\build.ps1
```

`dist\` 폴더에 `HighPen.exe`와 `HighPen-Setup.exe`가 만들어집니다.

```
build.ps1          빌드 스크립트
src\HighPen.cs     앱 소스
src\Setup.cs       설치 프로그램 소스
src\make-icon.ps1  아이콘 생성 스크립트 (HighPen.ico가 없으면 빌드 시 자동 실행)
dist\              빌드 결과물
```

## 참고 / 제한 사항

- 설치 파일에 코드 서명이 없어서 다른 PC에서 Windows SmartScreen 경고가 뜰 수 있습니다.
- 앱을 켠 뒤에 모니터를 연결하거나 빼면 모니터 목록이 갱신되지 않으므로 다시 실행해야 합니다.
- 모니터마다 화면 배율이 다른 환경에서는 확대나 설정바 위치가 어긋날 수 있습니다.
- 확대 중에 펜을 쓰려면 확대 화면이 포인터를 따라 움직이지 않도록 펜을 켜 둔 상태여야 합니다.
