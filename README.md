# HighPen

**한국어** | [English](README.en.md) | [日本語](README.ja.md)

비대면 강의용 Windows 펜 앱입니다. 화면 위에 바로 필기하고, 마우스 포인터를 스팟으로 강조하고, 화면을 확대하고, 칠판을 띄울 수 있습니다. 와콤 같은 펜 태블릿(Windows Ink)과 마우스를 모두 지원합니다.

![HighPen 설정바와 마우스 스팟](screen/전체화면1.png)

## 설치

### 설치 파일로 설치

1. [HighPen-Setup.exe](https://github.com/stepanowon/high-pen/raw/main/dist/HighPen-Setup.exe)를 다운로드해서 실행합니다.
2. 설치 여부와 바탕화면 바로가기 생성 여부를 선택합니다.
3. 설치가 끝나면 바로 실행할 수 있습니다.

- 설치 위치: `%LOCALAPPDATA%\Programs\HighPen` (관리자 권한 불필요)
- 시작 메뉴에 바로가기가 만들어집니다.
- 같은 파일을 다시 실행하면 덮어써서 업데이트됩니다.
- 제거: Windows 설정의 **설치된 앱**에서 HighPen을 제거하거나 설치 폴더의 `Uninstall.exe`를 실행합니다. 저장된 설정(`%APPDATA%\HighPen`)은 남습니다.
- 조용한 설치/제거: `HighPen-Setup.exe /S`, `Uninstall.exe /S`
- 설치 안내 문구는 Windows 표시 언어를 따릅니다(한국어, 일본어, 그 외에는 영어).

### 작업표시줄에 고정

앱을 실행하면 작업표시줄에 HighPen 아이콘이 나타납니다. 우클릭 → **작업 표시줄에 고정**을 선택하면 다음부터 앱이 꺼져 있어도 아이콘으로 실행할 수 있습니다.

### 설치 없이 실행

[HighPen.exe](https://github.com/stepanowon/high-pen/raw/main/dist/HighPen.exe)를 다운로드해서 바로 실행해도 됩니다.

### 요구 사항

Windows 10/11 (.NET Framework 4.8 포함, 별도 설치 불필요)

## 사용 방법

실행하면 작업 모니터의 좌측 상단에 설정바가 나타납니다. 설정바 맨 위 줄(HighPen)을 끌어 옮길 수 있고 위치는 기억됩니다. `<` 버튼으로 접고 펼 수 있습니다.

단축키는 전역 단축키라서 다른 프로그램을 쓰는 중에도 동작합니다. 다른 프로그램이 이미 쓰는 조합은 등록되지 않을 수 있습니다. 버튼에 마우스를 올리면 이름과 단축키가 툴팁으로 표시됩니다.

| 버튼 | 단축키 | 기능 |
|---|---|---|
| 스팟 | Ctrl+Alt+S | 마우스 포인터를 따라다니는 원형 스팟 켜기/끄기. 아래 화면의 클릭은 그대로 통과합니다. |
| 펜 | Ctrl+Alt+P | 화면 위에 필기. 펜을 끄면 필기는 화면에 남고 마우스는 아래 화면으로 통과합니다. 지우개/말풍선 상태에서는 펜으로 전환합니다. |
| 지우개 | Ctrl+Alt+E | 획 단위로 지웁니다. 지우개 상태에서 한 번 더 누르면 현재 페이지의 펜 필기와 말풍선을 모두 삭제합니다. |
| 칠판 | Ctrl+Alt+B | 흰 칠판 → 검은 칠판 → 끄기 순서로 전환. 화면 위 필기와 두 칠판의 필기는 각각 따로 보관됩니다. |
| 되돌리기 | Ctrl+Alt+Z | 마지막 획 하나를 취소합니다. |
| 지우기 | Ctrl+Alt+C | 현재 페이지의 필기와 말풍선을 모두 지웁니다. |
| 말풍선 | Ctrl+Alt+T | 클릭한 위치에 텍스트 메모를 붙입니다. Enter 확정, Shift+Enter 줄바꿈, Esc 취소. |
| 확대 | Ctrl+Alt+X | 마우스 포인터가 있는 모니터를 확대합니다. 배율은 설정에서 1.5배, 2배, 2.5배 중 선택합니다. |
| 설정 | Ctrl+Alt+D | 설정 패널을 열고 닫습니다. |
| `<` | Ctrl+Alt+H | 설정바를 접고 폅니다. |
| 빨간 X | Ctrl+Alt+Q | 종료 |

### 설정 패널

| 항목 | 단축키 | 설명 |
|---|---|---|
| 작동 모니터 | Ctrl+Alt+M (순환) | 앱이 동작할 모니터를 선택합니다. 필기, 스팟, 칠판, 설정바가 선택한 모니터에서만 나타납니다. |
| 펜 색상 | Ctrl+Shift+색상명 첫 글자 | 빨강 R, 주황 O, 노랑 Y, 초록 G, 파랑 B, 보라 P, 검정 K(B는 파랑이 사용), 흰색 W |
| 펜 두께 | | 1~30 |
| 필압 반영 | Ctrl+Alt+R | 펜을 세게 누를수록 선이 굵어집니다. 마우스는 설정한 두께로 일정하게 그려집니다. |
| 스팟 색상 / 크기 | | 색 8가지와 크기 20~200. |
| 언어 | | 한국어, 日本語, English 중에서 고르면 바로 바뀝니다. 처음 실행할 때는 Windows 표시 언어를 따르고, 한국어·일본어가 아니면 영어로 표시됩니다. |
| 버전 | | 패널 맨 아래에 현재 버전(`HighPen v1.1.0`)이 표시됩니다. |

설정은 자동 저장되며 `%APPDATA%\HighPen\settings.txt`에 있습니다.

### 확대 중 필기

확대 중에 펜을 켜면 확대 화면이 그 자리에 고정되어 보이는 위치에 그대로 필기할 수 있습니다. 펜을 끄면 확대 화면이 다시 포인터를 따라갑니다. 필기는 원래 화면 좌표로 저장되므로 확대를 끄면 같은 내용 위에 원래 크기로 남습니다.

## 기능 설명

### 마우스 스팟

마우스 포인터를 따라다니는 반투명 원형 스팟으로, 시청자가 포인터 위치를 쉽게 찾도록 도와줍니다.

- 스팟은 클릭을 가로채지 않아서 아래 화면을 평소처럼 조작할 수 있습니다.
- 색상(8가지)과 크기(20~200)는 설정 패널에서 바꿉니다. 테두리 없이 색만 있는 원입니다.
- 작동 모니터로 선택한 모니터에서만 표시됩니다.

### 펜 (필기)

화면 위에 투명한 필기 층을 덮어서 그대로 그립니다. 와콤 펜과 마우스 모두 사용할 수 있습니다.

![화면 위 필기](screen/펜1.png)

- **펜 켜기:** 펜을 켜면 화면이 필기 모드가 되어 아래 화면의 클릭이 막힙니다.
- **펜 끄기:** 그려 둔 필기는 화면에 남고, 마우스는 다시 아래 화면을 조작합니다. 필기 위에서 발표 자료를 넘길 수 있습니다.
- **색상과 두께:** 색 8가지, 두께 1~30. 색상은 단축키로도 바꿉니다.
- **필압 반영:** 켜 두면 펜을 세게 누를수록 선이 굵어지고, 설정한 두께는 중간 필압 기준입니다. 마우스는 설정한 두께로 일정합니다. 필압이 안 먹으면 와콤 드라이버에서 Windows Ink 사용이 켜져 있는지 확인합니다.
- **자동 보정:** 선은 부드러운 곡선으로 보정됩니다.

### 지우개

펜으로 그린 획 위를 지나가면 그 획 전체가 지워집니다(획 단위 지우기). 와콤 펜 뒤쪽 지우개 끝도 사용할 수 있습니다.

- 지우개 상태에서 Ctrl+Alt+E를 한 번 더 누르면 현재 페이지의 펜 필기와 말풍선이 한꺼번에 지워집니다. 다른 페이지에는 영향이 없습니다.
- 다시 쓰려면 펜 버튼(Ctrl+Alt+P)을 누릅니다.

### 칠판

화면 전체를 흰색 또는 검은색 칠판으로 덮고 그 위에 씁니다. 칠판 버튼을 누를 때마다 흰 칠판 → 검은 칠판 → 끄기로 바뀝니다.

- 화면 위 필기, 흰 칠판, 검은 칠판의 필기는 각각 따로 보관됩니다. 칠판을 껐다 켜도 내용이 유지되고, 칠판 필기가 화면 위 필기에 섞이지 않습니다.
- 검은 칠판에서 펜이 검정이거나 흰 칠판에서 펜이 흰색이면 안 보이므로 자동으로 반대 색으로 바꿉니다.
- 칠판에서는 확대 배율이 필기에 적용되지 않습니다.

| 흰 칠판 | 검은 칠판 |
|---|---|
| ![흰 칠판](screen/화이트보드.png) | ![검은 칠판](screen/블랙보드.png) |

### 되돌리기 / 지우기

- **되돌리기:** 현재 페이지에서 마지막으로 그린 획 하나를 취소합니다. 말풍선은 되돌리기 대상이 아닙니다.
- **지우기:** 현재 페이지의 필기와 말풍선을 모두 지웁니다. 다른 페이지(화면 위, 흰 칠판, 검은 칠판)에는 영향이 없습니다.

### 말풍선

화면에 텍스트 메모를 붙이는 기능입니다. 손글씨 대신 용어나 설명을 또렷한 글자로 남길 때 씁니다.

1. 말풍선 버튼(Ctrl+Alt+T)을 누릅니다. 포인터가 글자 입력 모양으로 바뀝니다.
2. 글을 놓을 위치를 클릭하고 내용을 입력합니다.
3. **Enter**로 확정합니다. **Shift+Enter**는 줄바꿈, **Esc**는 취소입니다.

- 흰 바탕에 현재 펜 색 테두리가 있는 둥근 상자로 표시되고, 글자 크기는 펜 두께에 비례합니다.
- 한 번 입력하면 일반 펜 모드로 돌아옵니다. 여러 개를 달려면 그때마다 버튼을 다시 누릅니다.
- 만든 뒤에는 위치를 옮기거나 고칠 수 없고, 지우기로만 삭제됩니다.
- 현재 페이지(화면 위, 흰 칠판, 검은 칠판)에 붙고 페이지별로 따로 보관됩니다.

![필기와 말풍선](screen/펜2.png)

### 화면 확대

마우스 포인터가 있는 모니터를 실시간으로 확대합니다. 배율(1.5배·2배·2.5배)은 설정 패널에서 고를 수 있으며, 확대 중에 바꾸면 바로 적용됩니다.

![화면 확대](screen/화면%20확대.png)

- 포인터 아래의 내용이 확대 후에도 포인터 바로 아래에 있도록 화면이 따라 움직입니다. 보이는 위치를 그대로 클릭하면 됩니다.
- 설정바는 확대되지 않고 원래 크기로 유지됩니다.
- 확대를 켠 순간 포인터가 있던 모니터가 확대되고, 확대 중에는 포인터가 그 모니터 밖으로 나가지 않습니다. 다른 모니터를 확대하려면 확대를 껐다가 포인터를 옮긴 뒤 다시 켭니다.
- **확대 중 필기:** 펜을 켜면 확대 화면이 그 자리에 고정되어 보이는 위치에 그대로 필기할 수 있습니다. 펜을 끄면 확대 화면이 다시 포인터를 따라갑니다. 필기는 원래 화면 좌표로 저장되므로 확대를 끄면 같은 내용 위에 원래 크기로 남습니다. 확대된 화면에서 다른 곳으로 옮기려면 펜을 끄고 포인터를 옮긴 뒤 다시 켭니다.

### 다중 모니터

설정 패널의 **작동 모니터**(또는 Ctrl+Alt+M)로 앱이 동작할 모니터를 고릅니다. 필기, 스팟, 칠판, 설정바가 그 모니터에서만 나타나고, 다른 모니터는 평소처럼 쓸 수 있습니다. 모니터를 바꿔도 기존 필기와 말풍선은 유지됩니다. 번호는 Windows 디스플레이 설정의 번호와 같습니다.

### 설정바

- 맨 위 줄(HighPen)을 끌어서 옮기면 위치가 저장되어 다음 실행 때 같은 자리에 나타납니다. 저장된 위치가 화면 밖이면 좌측 상단으로 돌아옵니다.
- `<` 버튼으로 접고 펼 수 있습니다. 접으면 아래처럼 HighPen 제목줄만 남습니다.

  ![접힌 설정바](screen/전체화면2.png)

- 각 버튼에 마우스를 올리면 이름과 단축키가 툴팁으로 표시됩니다.
- 클릭해도 발표 중인 화면의 포커스를 가져가지 않습니다.
- 실행 중에는 작업표시줄에 아이콘이 나타나고, 고정해 둘 수 있습니다.

### 설정 저장

펜 색상, 두께, 필압 반영, 스팟 색상과 크기, 스팟 켜짐 여부, 작동 모니터, 설정바 위치, 언어가 `%APPDATA%\HighPen\settings.txt`에 자동 저장되어 다음 실행 때 그대로 쓰입니다.

## 참고 / 제한 사항

- 설치 파일에 코드 서명이 없어서 다른 PC에서 Windows SmartScreen 경고가 뜰 수 있습니다.
- 앱을 켠 뒤에 모니터를 연결하거나 빼면 모니터 목록이 갱신되지 않으므로 다시 실행해야 합니다.
- 모니터마다 화면 배율이 다른 환경에서는 확대나 설정바 위치가 어긋날 수 있습니다.
- 확대 중에 펜을 쓰려면 확대 화면이 포인터를 따라 움직이지 않도록 펜을 켜 둔 상태여야 합니다.
