オンライン授業向けペンアプリの macOS 版です。macOS 14 (Sonoma) 以降で、Apple シリコンと Intel の Mac の両方に対応しています。

## ダウンロード

**[HighPen-1.1.0.dmg をダウンロード](https://github.com/stepanowon/high-pen/releases/download/macos-v1.1.0/HighPen-1.1.0.dmg)** (プレリリース [macos-v1.1.0](https://github.com/stepanowon/high-pen/releases/tag/macos-v1.1.0))

1. DMG を開き、HighPen を Applications フォルダーにドラッグします。
2. **初めて開く前に**、ターミナルで次のコマンドを実行します。警告なしでそのまま開けます。

```sh
xattr -dr com.apple.quarantine /Applications/HighPen.app
```

まだ Apple の公証を受けていないため、このコマンドなしで開くと「“HighPen”にマルウェアが含まれていないことを Apple は検証できません」という警告が出ます。**ゴミ箱に入れる**を押すとアプリが削除されるので、**完了**を押してください。その後、システム設定 > プライバシーとセキュリティ の下にある **このまま開く** を押してパスワードを入力すると開けます。すでにゴミ箱に移された場合は、Applications に戻してから上のコマンドを実行します。

> プレリリースです。App Store での配布と Apple の公証はまだありません。

## ビルド

Xcode は不要で、Command Line Tools だけで済みます (`xcode-select --install`)。

```sh
cd macos
./build.sh          # dist/HighPen.app を作成 (ユニバーサル、ad-hoc 署名)
./build.sh test     # ビルド後に自己チェックを実行
open dist/HighPen.app
```

バージョンは `build.sh` の `VERSION` の 1 か所で管理しています。

## DMG パッケージ

```sh
./build.sh dmg      # dist/HighPen-<バージョン>.dmg を作成
```

DMG を開き、HighPen を Applications フォルダーにドラッグするとインストールされます。

まだ Apple の開発者証明書による署名と公証 (notarization) を行っていないため、インターネットからダウンロードした DMG のアプリは初回起動時にブロックされます。開き方は[ダウンロード](#ダウンロード)をご覧ください。

警告なしで配布するには、Apple Developer Program に登録して Developer ID 署名と公証を行う必要があります。

### ショートカットの変更

設定 > **ショートカット設定** で項目をクリックし、新しい組み合わせを押すと変更されます。Esc で取り消し、Delete でショートカットなし、**既定に戻す** ですべて元に戻ります。⌃、⌥、⌘ のいずれかと一緒に押す必要があり、F1~F20 は単独で使えます。ほかの項目で使っている組み合わせや、ほかのアプリが使用中の組み合わせは案内が表示されます。

ツールバーは上部をドラッグして移動でき、位置と設定は自動的に保存されます。Dock アイコンをクリックすると、折りたたんだツールバーが再び展開されます。ツールバーや設定項目にポインターを合わせると、名前とショートカットが表示されます。

ペン・蛍光ペン・消しゴムをオンにすると、ポインターがその道具の形に変わります。macOS ではアクティブなアプリしかポインターの形を変えられないため、ペンモード (とショートカット設定ウインドウ) の間は HighPen がアクティブになり、終わると元のアプリ (スライドショーなど) に戻ります。そのため、ペンモード中はキーボード入力 (スライド送りなど) が元のアプリに届きません。HighPen のショートカットは常に使えます。

## 権限

拡大とキャプチャには **画面収録** の許可が必要です。初めて使うときに案内が出たら、システム設定 > プライバシーとセキュリティ > 画面とシステムオーディオの録音 で HighPen をオンにし、**HighPen を終了して再起動** してください (macOS は再起動しないと許可を反映しません)。

再ビルドしても許可が保たれるよう、バンドル ID (`com.stepanowon.HighPen`) を基準に署名しています。以前のビルドでオンにした許可が効かない場合は、`tccutil reset ScreenCapture com.stepanowon.HighPen` でリセットしてから再度オンにしてください。

## Windows 版との違い

- ショートカットは `Ctrl+Alt` の代わりに `⌃⌥` (Control+Option) を使います。ペンの色はほかのアプリと重ならないよう `⌃⌥1~8` に変更しました。
- まだない機能: 吹き出し、クリック表示。
- 拡大中にポインターをモニター内に閉じ込めません (macOS に該当する機能がないため)。

## 構成

| パス | 内容 |
|---|---|
| `src/HighPen.swift` | アプリ全体 (AppKit、ScreenCaptureKit、Carbon ショートカット) |
| `src/make-icon.swift` | アプリアイコンの生成 (Windows のアイコンと同じデザインを macOS のアイコン規格に合わせてサイズごとに描画) |
| `build.sh` | `swiftc` で arm64・x86_64 をビルド → `lipo` → `.app` バンドル作成、アイコン生成、ad-hoc 署名、DMG パッケージ作成 |
